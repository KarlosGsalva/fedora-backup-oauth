Fedora Backup

Fedora Backup is a personal backup solution for securely storing and restoring Linux development environments using Google Drive.

Purpose

The application uses rclone to connect to Google Drive and restic to create encrypted, incremental backups.

What is backed up?

  • Development projects and source code
  • Application configuration files
  • Selected Docker volumes and application data
  • Selected system and user configuration files

Security

Backup contents are encrypted locally by restic before being uploaded to Google Drive. The backup password is not sent to Google Drive.

Google Drive Access

The application requests the Google Drive drive.file permission to create, access, and manage files used by this application.
