Privacy Policy

Last updated: November 9, 2026

1. Overview

Fedora Backup is a personal application for backing up and restoring Linux development environments using Google Drive, rclone, and restic.

2. Google Drive Access

The application uses Google OAuth 2.0 and requests the drive.file permission. This permission allows access to files created or opened with the application.

3. Data Processing

Selected local files are encrypted by restic before being uploaded to the user's Google Drive account. Backup contents are not transmitted in plaintext.

4. Data Storage

Encrypted backups are stored in the user's own Google Drive account. OAuth credentials and encryption passwords are stored locally and are not intentionally included in backups.

5. Data Sharing

The application does not sell personal information or intentionally share backup contents with third-party services beyond the selected Google Drive storage provider.

6. Data Retention and Deletion

Backups remain in Google Drive until they are deleted by the user or removed according to configured backup retention rules.

7. Security

Restic encrypts backup contents locally. Users are responsible for protecting their encryption passwords and OAuth credentials.

8. Contact

For questions, contact the application owner through the associated GitHub repository.
